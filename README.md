# Mao Online

Real-time multiplayer Mao — **absolute sandbox mode**. The server is a physical card table: it shuffles, deals, and tracks hands, but enforces zero rules. Players notice violations and penalize each other.

> **Built entirely by AI.** Every line of code, the card art, the tanbi kei styling, and the multi‑tab end‑to‑end verification — all generated by an AI coding agent (OpenCode).
>
> Models used — **Kimi K3** & **Opus 5** (UI & artwork), **DeepSeek V4 Pro** (planning & architecture), **DeepSeek V4 Flash** (simple coding tasks).

## Quick start

```bash
npm install
npm start        # binds 0.0.0.0:3000
```

Open `http://localhost:3000` — create a room, share the 4‑letter code. Other players join on the same Wi‑Fi or LAN.

## How to play

1. **Create or join a room** — pick a name, type the room code (joiners only).
2. **Deal** — the host clicks **Deal 3** or **Deal 5**. Cards are private; counts and the discard pile are public.
3. **Play** — tap a card to play it. Draw from the deck. Penalize other players when they break a rule — they draw a penalty card.
4. **Leave** — the Leave button in the top‑right corner of the table returns you to the join screen.

There is no turn order, no rule enforcement, and no concept of winning. The server validates only that a card is in your hand and that a penalty target exists. Everything else is up to the humans at the table.

## Architecture

```
server.js          — Express 5 + Socket.io, room lifecycle, all game events
game.js            — pure deck engine, shuffle, room factory (no I/O)
public/index.html  — join screen → game screen
public/style.css   — tanbi kei (耽美) theme, hand‑crafted CSS
public/cards.js    — real‑deck SVG card faces: pip layouts, double‑headed court figures
public/client.js   — socket wiring, incremental DOM (roster, log, hand fan)
```

No bundler, no framework, no build step. Card art is inline SVG generated by `cards.js`; all styling is custom CSS classes. Rooms hold up to 50 players; state is in‑process and lost on restart.

## Developing

```bash
npm run dev        # nodemon auto‑restart
```

Lint, tests, and CI are out of scope — verification is manual. See `build-spec.md` for the full socket contract, data model, and multi‑tab checklist. `AGENTS.md` records server invariants, client conventions, and gotchas for future work.
